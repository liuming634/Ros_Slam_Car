# common 通用工具包

本目录存放所有ROS2功能包共享的通用工具函数、数据结构和基础代码，避免重复编写相同的功能，提高代码复用性和可维护性。

## 主要功能

### 1. 通用工具函数库
- 数学计算工具：坐标转换、欧拉角/四元数转换、向量/矩阵运算、滤波算法等
- 字符串处理、文件操作、日志调试等通用工具
- ROS2通信封装：话题、服务、参数的通用调用封装

### 2. 通用数据结构
- 不适合单独放到msgs包中的轻量级数据结构体
- 通用的传感器数据格式、位姿数据结构等

### 3. 硬件抽象通用代码
- 串口通信、USB设备检测等通用底层工具
- 多个硬件模块共享的硬件操作接口

### 4. 业务通用工具
- 数据序列化/反序列化工具
- 状态机、任务队列等通用编程范式实现

## 目录结构
```
common/
├── include/common/        # 通用头文件目录
├── src/                   # 通用源代码目录
├── CMakeLists.txt         # 编译配置
├── package.xml            # 包依赖声明
└── README.md              # 本说明文档
```

## 使用说明
本包作为依赖被其他功能包使用，无需单独启动。在其他包的CMakeLists.txt和package.xml中添加对common的依赖即可调用其中的工具函数。
